## About the project
UFlow Planner helps students manage their academic and personal activities in one place,
so they do not need several separate apps.

**Live site:** https://uflow-zeta.vercel.app

### Features
- Sign up and sign in with email and password or Google, with password reset
- Tasks with due dates, completion, XP and levels
- Calendar with week and month views, synced with Google Calendar
- Reminders with ringtones, snooze, desktop notifications and a notification drawer
- Notes with automatic saving, and PDF document storage
- Dashboard with streak, Flow Score and focus progress
- Focus timer with a daily goal
- Medicine reminders with daily dose tracking
- Global search (Ctrl+K)

### Technology
React 19, TypeScript, Vite, Tailwind CSS v4, Firebase Authentication, Cloud Firestore,
Google Calendar API, hosted on Vercel.
